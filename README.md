# Spotify Backend Clone

A backend application built with Node.js, Express.js, MongoDB, JWT Authentication, and ImageKit.

## Features

- User Registration
- User Login
- JWT Authentication
- Cookie-based Authentication
- Artist & User Roles
- Role-based Authorization
- Upload MP3 files
- ImageKit Cloud Storage
- MongoDB Database
- REST APIs

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer
- ImageKit
- Cookie Parser
